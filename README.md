# Hey, This is Aaryan

I am a software engineer who likes building products end to end, from mobile apps and backend systems to AI tooling and experimental ML.

Right now I am building [Infimium-agent](https://infimium.com/), a local-first context layer for AI coding agents. It gives agents persistent context, semantic code search, and repository awareness, so they understand a project beyond a single prompt and keep continuity across sessions. I am also working on how agent-driven code changes are planned, traced, and verified. That part is still private.

I am also building KlubEATS, a Flutter platform for enterprise food ordering and vendor operations. It covers employee ordering, meal booking, QR-based entitlements, payments, vendor workflows, feedback, analytics, and repeat orders.

Playground.ai is under construction and releasing soon. It is a visual canvas for designing app and web interfaces and converting them into UI code in React, CSS, Dart, and more.

On the ML side, I built a LightGBM fraud detection system over 6.36M+ transactions, using SMOTE for class imbalance and SHAP to find the strongest fraud signals ([Notebook](https://colab.research.google.com/drive/1KyxupQPFrbNmqSBgvbwzGS5NJW3TbIuU?usp=sharing)). I also built an LSTM stock-price prediction pipeline in Python, evaluated with RMSE and MAE ([Notebook](https://colab.research.google.com/drive/1xCk4rKimMUlo4Mq3ubAdAGtSfEyM9Ko0?usp=sharing)).

My recent research is Salience-Gated Slot Memory for State-Space Models (SG-SSM). It adds a bounded memory that runs alongside the normal SSM recurrence and keeps rare, high-salience information in dedicated slots instead of squeezing everything into one shared state. At read time, the memory output is combined with the SSM output ([Research notebook](https://colab.research.google.com/drive/14FJbt3LcrX_poJYT4vQnL7LnEe6_s6Ym?usp=sharing)).
